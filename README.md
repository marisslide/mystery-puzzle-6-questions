# Vietnam Cultural Journey – Mystery Puzzle (6 Questions)

Trò chơi ô chữ / lật hình khám phá văn hóa Việt Nam (Vietnam Cultural Journey - Mystery Puzzle 6 Questions) được xây dựng dưới dạng ứng dụng web độc lập (Standalone Single-Page Web App).

## 🚀 Tính năng
- 6 câu hỏi tương ứng 6 mảnh ghép che bức tranh bí ẩn (Final Poster).
- Tự động đếm ngược thời gian cho mỗi câu trả lời.
- Hiệu ứng mở mảnh ghép mượt mà kèm pháo hoa (confetti).
- Tích hợp bảng cấu hình (nút bánh răng) để chỉnh sửa câu hỏi hoặc thay đổi ảnh poster trực tiếp.
- Tối ưu hiển thị responsive 16:9, dễ dàng nhúng vào iSpring Suite 11 hoặc trình chiếu trên lớp học.

## 📁 Cấu trúc thư mục
- `index.html`: File ứng dụng chính chạy trên trình duyệt / Vercel.
- `mystery_puzzle_6_questions.html`: Bản gốc độc lập đã nhúng sẵn dữ liệu poster.
- `vercel.json`: Cấu hình tối ưu định tuyến và Clean URLs cho Vercel.
- `README_mystery_puzzle.txt`: Hướng dẫn sử dụng ban đầu.

## 🌐 Triển khai trên Vercel
1. Đẩy mã nguồn lên kho lưu trữ GitHub của bạn.
2. Đăng nhập [Vercel](https://vercel.com) và chọn **Add New...** > **Project**.
3. Chọn kho lưu trữ GitHub này và bấm **Deploy**.
4. Vercel sẽ tự động nhận diện dự án tĩnh (Static Site) và triển khai chỉ sau vài giây.
