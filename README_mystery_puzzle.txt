VIET NAM CULTURAL JOURNEY – MYSTERY PUZZLE (6 QUESTIONS)

Files:
- mystery_puzzle_6_questions.html: one-file version. The supplied final poster is embedded inside the HTML, so no separate image file is required.

How to use:
1. Open the HTML file in Chrome or Edge. An internet connection is required for the React/Babel and Google Fonts CDN files included in this version.
2. Click any of the six puzzle tiles.
3. Answer the English question within the countdown. A correct answer reveals one part of the supplied poster.
4. After all six parts are revealed, the final poster appears. Use VIEW FINAL POSTER to enlarge it.
5. Open the gear icon to edit questions or replace the final poster.

For iSpring Suite 11:
- Host the HTML file on an HTTPS web host and insert its URL as a Web Object, or open the HTML locally to preview.
- The game is designed for a responsive 16:9 landscape display.
